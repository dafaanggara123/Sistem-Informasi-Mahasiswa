# Dokumentasi Kontribusi SIM

## Tujuan
Dokumentasi ini dibuat sebagai simulasi kontribusi
proyek Sistem Informasi Mahasiswa melalui GitHub.

## Proses Kontribusi
1. Melakukan Fork repository utama.
2. Melakukan Clone repository Fork.
3. Membuat branch kontribusi.
4. Membuat perubahan dokumentasi.
5. Melakukan commit dan push.
6. Mengajukan Pull Request ke repository utama.
